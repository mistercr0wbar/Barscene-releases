# Barscene

GIF and short-video editor for Windows, made by Bardevco.

[Barscene product page](https://bardevco.com/apps/barscene) ·
[Latest release](https://github.com/mistercr0wbar/Barscene-releases/releases/latest)

Choose Setup for installation and in-app upgrades, the ZIP for portable use,
or the standalone executable. Windows 10/11 x64 and Microsoft Edge WebView2
Runtime are required. Capture, projects and media processing stay local.

Barscene succeeds Bardrop. Existing installations can upgrade through the
original BarDrop-releases channel; their settings and library paths are kept.
Barscene checks this repository for future updates.

Update feeds are signed and installers are checked against their signed
SHA-256 digest. The executables do not have an Authenticode publisher
certificate; Windows may display an unknown-publisher warning.

Each release includes third-party notices, the full corresponding FFmpeg
9.0.2 source, its build recipe and checksums. FFmpeg is an LGPL build without
GPL or nonfree components. This repository distributes the application;
it does not make the private application source public or change its terms.
